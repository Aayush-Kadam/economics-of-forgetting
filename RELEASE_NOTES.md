# v0.9.0-rc1 — local external-review candidate

## Core contribution

The release contains a theory-first working paper on lifecycle asymmetry in persistent institutional records. In a finite-horizon score-based control problem, record persistence can strengthen ex ante discipline while reducing productive post-event effort on a nonempty region. Record-dependent effort can also create future-quality differences at zero intrinsic persistence.

## Scientific narrowing

The project began with a broad optimal-forgetting hypothesis. Successive proof, numerical, and literature audits rejected a universal interior half-life, a fixed prediction-versus-welfare ordering, global self-fulfilling reputation, broad earned forgetting, and general superiority of memory over direct punishment. The lifecycle-contingent design result is retained only as an appendix illustration.

## Reproducibility

- Core and full reproduction entry points.

## Known limitations

The opportunity schedule is reduced form; the model is finite horizon; false-positive signals, alternative timing, Bayesian market response, infinite-horizon equilibrium, and global continuous memory optimization are unresolved. Numerical magnitudes are normalized model outputs, not empirical estimates.

This candidate is local and unpublished. It has not been submitted to a journal or external repository.
