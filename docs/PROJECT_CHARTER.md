# Project Charter

## Question

How should institutions remember, discount, expire, or forgive past information when reputation affects both beliefs and incentives to change?

## Central distinction

- **Informational persistence:** history predicts outcomes because underlying quality is persistent.
- **Behavioral persistence:** history changes opportunities, opportunities change rehabilitation effort, and effort changes future quality.

## Scientific commitments

1. Resolve literature collision before developing the model.
2. Separate theory, numerical evidence, calibration, and causal evidence.
3. Preserve counterexamples, failed conjectures, and boundary optima.
4. Verify every citation and make every quantitative output reproducible.
5. Attribute authorship solely to Aayush Kadam.

## Milestone gate

M0 passes only if the combination of endogenous rehabilitation, quality-changing effort, reputation-dependent opportunities, and institutionally chosen memory is not already substantially present in one paper. Otherwise the project must narrow or pivot.
