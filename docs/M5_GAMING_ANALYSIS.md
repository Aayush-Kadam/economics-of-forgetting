# M5 Gaming Analysis

The state includes offense count and favorable streak. A new adverse event resets the streak; recovered agents may offend again. This directly tests misconduct–rehabilitate–reoffend cycles.

The benchmark optimal constant and lifecycle rules generate approximately `.500` expected misconduct events and no repeat events within six periods. The optimal rule uses `m=1`, but no threshold bunching produces a cycle before the horizon. Thus gaming does not destroy the reported gain, yet this is a weak negative result: the short horizon and deterministic favorable signal limit recurrence. No claim of gaming-proof earned relief is made.
