# M7 direct-punishment comparison

A detected-offense penalty was added to the agent's deterrence threshold and treated as a transfer, consistent with the welfare convention. Constant memory plus the largest tested penalty improves welfare from -0.45549 to -0.02733 and therefore dominates the baseline two-state/no-penalty welfare of -0.41557.

However, direct punishment does not make state contingency redundant in this model: with penalty 2, the optimized two-state rule reaches 0.24481, a further gain of 0.27213 over the best constant rule at that penalty. The instruments are complements in the computed environment.

This benchmark is deliberately stark. It assumes costless, perfectly enforceable transfers and does not model legal, liquidity, or limited-liability constraints. The memory mechanism is second-best relative to an unconstrained penalty-only comparison, but retains incremental value when both instruments are available.
