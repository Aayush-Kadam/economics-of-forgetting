# M7 timing robustness

The implemented model retains the canonical sequence: current score determines current access; effort changes next quality; the score then updates; misconduct sends a detected agent to the adverse lifecycle state. M4.5's corrected discrete recovery time remains in force.

A genuinely different within-period timing requires re-solving the agent problem because effort, misconduct, and current access would become jointly endogenous. M7 did not implement that new game. This is a major unresolved robustness item and one reason the verdict cannot exceed PASS WITH LIMITATIONS. No claim of timing invariance is made.
