# M6 Counterexamples

- Adaptive memory is negligible at 3 design points.
- Three-state memory adds no value beyond two-state memory at 24 points.
- Threshold flexibility adds no value beyond P2 at 17 points.
- Prediction memory can be longer, shorter, or equal to welfare memory.
- Positive recurrence occurs at only 7 points; gaming conclusions are not universal.
- The proposed memory-conflict index has correlation about `-.09` with adaptive value and fails as an organizing sufficient statistic.
- `rho=0` does not guarantee positive adaptive value: 3 of 12 zero-rho points have no strict gain.

No new theorem is inferred from design frequencies.
