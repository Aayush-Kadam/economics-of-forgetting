# M5 Counterexamples

- Earned forgetting need not beat constant decay: it collapses exactly to the fixed optimum in the benchmark.
- State contingency can have zero value (`alpha=0` with low misconduct harm; high-alpha/zero-harm cells).
- The optimal policy can remember adverse histories more strongly than clean histories.
- Productive rehabilitation is not necessary for all adaptive value: with `alpha=0` and high misconduct harm, lifecycle deterrence still creates gains.
- Greater rehabilitation productivity does not monotonically increase flexibility value.
- Better welfare need not require worse prediction: the benchmark lifecycle rule improves both welfare and forecast MSE.

These failures prohibit branding the result as universal earned forgiveness.
