# M7 heterogeneity

A common policy was optimized for equal mixtures of low/high rehabilitation productivity and low/high intrinsic persistence. Gains over a common constant rule are 0.05595 and 0.06448. This shows that limited latent heterogeneity does not mechanically eliminate common-rule value.

The exercise does not include heterogeneous discounting, private benefits, signals, or joint continuous type distributions, and it does not compute a full-information personalized upper bound. It supports only a narrow common-policy result.
