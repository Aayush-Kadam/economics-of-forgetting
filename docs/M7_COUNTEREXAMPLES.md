# M7 counterexamples

- M6.5 indices 1 and 3: state contingency has exactly zero value at rho=0, alpha=.3, T=12.
- Linear opportunity: gain is only 0.000270, economically negligible.
- Logistic slope 3: gain is 0.003686, positive but small.
- Some population compositions produce gains below 0.001.
- Direct punishment alone can dominate the no-penalty two-state benchmark.
- Exact prediction/welfare alignment largely disappears under refined memory meshes.

These examples rule out universal, large, and uniquely memory-based claims.
